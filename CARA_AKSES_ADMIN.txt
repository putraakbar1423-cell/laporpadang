=============================================
  TROUBLESHOOTING
=============================================

Q: Server running tapi browser "tidak dapat terhubung"?
A: Check:
   1. Firewall allow port 8000
   2. Antivirus tidak blokir
   3. Pakai http:// bukan https://
   4. URL correct: /admin/dashboard

Q: 404 Not Found?
A: Check:
   1. Routes registered:
      php artisan route:list --name=admin
   2. Include admin.php di web.php:
      require __DIR__.'/admin.php';

Q: Redirect ke login terus?
A: Admin user belum dibuat:
   php artisan tinker
   User::create([...])

Q: Page error 500?
A: Check logs:
   storage/logs/laravel.log

Q: CSS tidak load?
A: Check inline CSS di blade file

=============================================
  FIREWALL SETTINGS (jika perlu)
=============================================

Windows Firewall:
1. Control Panel > Windows Defender Firewall
2. Advanced Settings
3. Inbound Rules > New Rule
4. Port > TCP > 8000
5. Allow connection
6. Apply

Atau cepat via CMD (as Administrator):
  netsh advfirewall firewall add rule name="Laravel Dev" dir=in action=allow protocol=TCP localport=8000
