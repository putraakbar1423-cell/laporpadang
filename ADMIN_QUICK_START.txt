=============================================
  TROUBLESHOOTING
=============================================

Q: Sidebar tidak muncul?
A: - Check route registered: php artisan route:list
   - Check middleware: auth, admin
   - Check user role: 'admin'

Q: CSS tidak load?
A: - Clear cache: php artisan view:clear
   - Check inline CSS di admin.blade.php
   - Refresh browser (Ctrl+Shift+R)

Q: Charts tidak muncul?
A: - Check Chart.js CDN
   - Check browser console untuk errors
   - Verify data format di controller

Q: Icons tidak muncul?
A: - Check Font Awesome CDN
   - Internet connection OK?
   - CDN not blocked by firewall?
